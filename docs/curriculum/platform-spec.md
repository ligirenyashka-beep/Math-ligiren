# Спецификация платформы: сайт, заявки, личные кабинеты

## Принцип «сначала просто» (из Концепции, Часть X)
Без бюджета на серверы и команду: статический сайт + localStorage + опциональный бесплатный бэкенд (Supabase free / GitHub Pages). Полноценный бэкенд — при появлении платящих пользователей.

## Что уже есть в репозитории
- `site/` — Next.js-прототип (из developing-pingli-academy-platform.zip): страницы обучения по классам, теория, практика (генераторы заданий), прогресс, экзамены.
- В этой итерации добавлено: полный курс 1–11 (данные), страница заявок, личный кабинет (localStorage), дашборд родителя (прототип).

## Страницы сайта

| Страница | Назначение |

| `/practice/[topic]` | Тренажёр (генераторы заданий, автокоррекция) |
| `/exams` | ОГЭ/ЕГЭ: структура, кодификатор, пробники |

| `/cabinet` | **Личный кабинет ученика:** прогресс по темам, звёзды/артефакты, повторения (интервалы 1–3–7–14–30), рекомендации |

| `/teacher` | **Кабинет педагога (прототип):** группа до 30 детей, назначение траекторий, мониторинг, отчёты |

## Личные кабинеты: данные (localStorage, без сервера)

```ts
// Ключи localStorage
pingli:learner        // { clientId, name, grade, createdAt }
pingli:progress       // { [topicId]: { solved, correct, mastered, stars, updatedAt } }
pingli:applications   // [ { id, name, grade, goal, contact, time, createdAt } ]
pingli:settings       // { character, theme, sound }
```

- Приватность: данные только в браузере; экспорт/импорт JSON; удаление по запросу (152-ФЗ, GDPR-Kids).
- При подключении бэкенда: те же сущности в PostgreSQL (см. `site/src/db/schema.ts` в исходном zip: learners, topic_progress).

## Заявки: поток
1. Родитель/ученик заполняет `/apply` (2 минуты).
2. Заявка сохраняется локально + показывается подтверждение с номером заявки.
3. Администратор (будущее): список заявок в `/admin` (прототип — экспорт JSON/CSV).
4. При бэкенде: POST `/api/applications` → база → уведомление.

## Дорожная карта (из Концепции, Часть XII)

| Фаза | Длительность | Что делаем | Бюджет |
|---|---|---|---|
| 0: Фундамент | 3–4 мес. | Методология (этот курс), дизайн, 5–10 прототипов тренажёров, тест на 5–10 детях | 0–50 тыс. ₽ |
| 1: MVP дошкольный | 6–9 мес. | Дочисловой период (7 блоков, ~40 микронавыков), сайт, PDF | 50–150 тыс. ₽ |
| 2: Пилот младшая школа | 9–12 мес. | «Рождение числа», «Числа и операции», пилот 100–500 семей | 150–300 тыс. ₽ |
| 3: Расширение | 12–18 мес. | До 10 лет, монетизация, первые педагоги | 300–500 тыс. ₽ |
| 4: Полный цикл | 18–24 мес. | До 15+ лет, международная версия, мобильное приложение | При выручке |

Критерии перехода: 0→1 — дети понимают задания, родители видят ценность; 1→2 — retention >60% за 3 мес.; 2→3 — платящие покрывают расходы; 3→4 — устойчивый рост.

## Видео и мультфильмы: план производства
1. Сценарии и раскадровки (см. characters-video-intensives.md) — сейчас.
2. Пилот: 3 видео (по одному на возрастной блок) — следующий этап.
3. Сезоны мультфильмов — после пилота и подтверждения retention.
4. Интенсивы — текстовые + видео, запускаются раньше мультфильмов (меньше затрат).

## Технические требования
- Сайт: Next.js (уже в `site/`), статический экспорт возможен; хостинг — GitHub Pages / Netlify (бесплатно).
- Аналитика: простая (без слежки за детьми); Google Analytics — опционально, только для взрослых страниц.
- Доступность: VoiceOver/TalkBack, тап-зоны ≥44px, дублирование цвета формой.

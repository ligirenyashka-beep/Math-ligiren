## Как читать курс

Каждый класс описан одинаково:

1. **Цель класса** — что ученик умеет в конце года (измеримо).
2. **Часы** — по ФГОС/ФООП + надстройка Пингли (кружок/интенсив).
3. **Темы по четвертям** — последовательность с обоснованием (почему так, а не иначе).
4. **Привязка к ФИПИ** — коды кодификатора ОГЭ/ЕГЭ, где применимо.
5. **Надстройка** — Сириус.Курсы, МГУ, олимпиадные темы.
6. **Нейроокно** — сензитивный период и как его использовать.
7. **Международный опыт** — что взято из Кореи/Китая/Сингапура/СССР.
8. **Контроль** — домашки, самостоятельные, контрольные, срезы.
9. **Медиа** — идеи видеоурока, мультфильма, интенсива, конспекта.

## Принципы (из Концепции Пингли Академии)

- **Открытие → Автоматизация.** Сначала ТРИЗ-противоречие и понимание, затем тренировка до автоматизма (Монтессори-повторение, интервальные повторения).
- **CPA:** конкретное → наглядное → абстрактное (Сингапур/Брунер). Каждый новый объект сначала трогаем, потом рисуем, потом записываем символами.
- **Ошибка — данные.** Автокоррекция среды без оценок и таймеров давления.
- **Зона ближайшего развития** (Выготский): задания на грани возможностей, с подсказкой.
- **Интерливинг и интервальное повторение:** 1–3–7–14–30 дней.
- **Гибрид физический + цифровой** в младшем возрасте, полностью цифровой с 12+ лет.

## Полноценный онлайн-курс (готовый, в `site/`)

Раздел **«Онлайн-курс»** (`/course`) — академический, методологически и практико-ориентированный курс:

- **11 классов, 44 главы, 132 темы** — каждая тема: теория (конспект с формулами и примерами) + практика (генераторы заданий с автокоррекцией) + домашнее задание (чек-лист) + контрольный тест с объяснениями.
- Структура: `/course` (хаб с прогрессом) → `/course/[grade]` (программа класса по главам) → `/course/[grade]/[topic]` (урок с вкладками Теория / Практика / Домашка / Тест).
- Прогресс сохраняется в localStorage (без сервера); при `DATABASE_URL` — PostgreSQL.
- Данные курса: `site/src/lib/course.ts` (генерируется из программ классов).

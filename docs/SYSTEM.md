# Система вирусных математических каруселей — Полная спецификация

Построена по ТЗ из 11 разделов. Реализована как гибрид: Canva-шаблоны + локальный движок генерации.

## 1. Роль
Креативная студия: редактор тем, сценарист, математик, копирайтер, художник, арт-директор, контролёр качества.

Цель: листают из любопытства, понимают без подготовки, запоминают и пересылают.

## 2. Принцип истории
Запрет: «заголовок+абзац+картинка». Формула:
Интуиция → Противоречие → Любопытство → Эксперимент → Объяснение → Доказательство → Эмоц.точка

## 3. Выбор тем
Приоритет: парадоксы, деньги/скидки, время, бытовые споры, масштаб, ошибки интуиции, школьные правила без смысла.

## 4. Драматургия
- 1 слайд: хук 1-2 сек, конфликт, не раскрывать ответ
- Средние: смена ракурса, позы, масштаба. Каждый слайд = 1 новая мысль
- Кульминация: формула как событие (крупный центр)
- Финал: вывод + CTA сохранить/отправить/@tononame

## 5. Визуальный язык
Stickman cartoon + журнальная типографика. Толстая контурная линия, плоские заливки, живой штрих, стрелки-каракули.
Герой единый на всех слайдах. Палитра строго 6 цветов.

## 6. Типографика
1080×1350, поля 72px, Unbounded/Manrope/Caveat, иерархия 5 уровней, асимметрия, диагонали.

## 7. Иллюстрация объясняет
Картинка = инструмент доказательства, а не декор. Абстракция → действие → схема → формула.

## 8. Мат.проверка
Таблица 5 колонок обязательна. Красный статус блокирует релиз.

## 10. Финальный пакет
Название, таблица, тексты, промпты, схема Canva, 3 подписи, хештеги, возражения, What to remember.

## 11. Референсы
Анализируем как арт-директор, извлекаем принципы. Не копируем.

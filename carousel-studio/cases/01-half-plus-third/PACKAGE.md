## Таблица математической проверки (Этап 4)

| Утверждение | Формула | Данные и допущения | Результат | Статус |
|-------------|---------|--------------------|-----------|--------|
| 1. Ошибочное сложение 1/2+1/3 как 2/5 | 1/2+1/3 = (1+1)/(2+3) = 2/5 =0.4 | Допущение: складываем числители и знаменатели отдельно (ошибка) | 0.4 ≠ 0.833… (истинное 5/6) | 🔴 демо ошибки |
| 2. Истинная сумма через НОК | 1/2+1/3 = 3/6+2/6 =5/6 | НОК(2,3)=6, 6÷2=3, 6÷3=2 | 5/6 ≈0.8333 | 🟢 проверено Python |
| 3. Визуальная модель пиццы | 1/2 =3/6 (пол-пиццы =3 из 6 кусков), 1/3=2/6 | Пицца разрезана на 6 равных частей | 3/6+2/6=5/6, остаётся 1/6 | 🟢 |
| 4. Проверка 1/4+1/6 (тест в карусели) | НОК(4,6)=12, 1/4=3/12, 1/6=2/12, сумма=5/12 | НОК=12 (мин. делится на 4 и 6) | 5/12≈0.4167 | 🟢 |
| 5. Последовательные скидки (бонус-сравнение) | 1000×0.5×0.5=250 (потеря 75%) | Две скидки применяются последовательно | 250≠0 | 🟢 (для идеи №3, не для этой карусели) |

**Вычисление (Python):**
```python
from fractions import Fraction
print(Fraction(1,2)+Fraction(1,3)) # 5/6
print(Fraction(1,4)+Fraction(1,6)) # 5/12
```
Статус всех ключевых утверждений 🟢. Красный статус только у демонстрируемой ошибки (2/5) — это намеренно.

## 3 возражения и ответы

1. «Но в школе учили складывать так!» → Ответ: Учили складывать только одинаковые куски (знаменатели). Если разные — сначала приводим к общему (НОК). Иначе как сложить половинку и треть разного размера?
2. «Зачем мне дроби, я взрослый» → Ответ: Это про скидки, рецепты, время, делёжку. Мозг ошибается одинаково везде, где есть части. Потренируешься на пицце — не ошибёшься в магазине.
3. «Слишком просто/детское» → Ответ: Попробуй тест из карусели: 1/4+1/6. Если ответил 2/10 — ты в 90%. Сохрани алгоритм 3 шагов.

## Блок «Что запомнить»
- Знаменатель — это размер куска. Разные размеры складывать нельзя.
- Общий знаменатель = НОК — самое маленькое общее кратное.
- Алгоритм: НОК → дополнительные множители (6÷2=3) → новые числители → складываем верх, низ тот же.
- Пример-якорь: 1/2=3/6, 1/3=2/6 → 5/6 (а не 2/5).

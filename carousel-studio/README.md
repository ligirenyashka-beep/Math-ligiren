# Система создания вирусных Instagram-каруселей — Carousel Studio

## Архитектура
- `studio.html` — главный визуальный редактор (1080×1350, палитра, типографика, stickman-персонаж)
- `engine/` — движок рендера (Canvas API → PNG экспорт)
- `templates/` — 7 композиционных шаблонов слайдов (хук, конфликт, эксперимент, кульминация, вывод)
- `assets/` — стикмен, иконки, текстуры бумаги
- `carousels/` — готовые пакеты (JSON + PNG)

## Палитра (обязательная)
- белый #FFFFFF
- бежевый #F3E7D3
- коричневый #5A3A29
- оранжевый #E8590C
- бордовый #6E1423
- почти чёрный #1A1411

## Шрифты
- Unbounded (заголовки)
- Manrope (основной)
- Caveat (рукописные реплики)

## Формат слайда
- 1080×1350 px (4:5)
- Поля 72 px
- Заголовок ≥ 64 px, основной ≥ 36 px
- Номер слайда 1/n внизу

## Workflow (8 этапов)
0. Журнал уроков → 1. Идея (6 вариантов) → 2. Уточнения → 3. Раскадровка (A/B) → 4. Мат.проверка → 5. Тексты → 6. Визуал → 7. Контроль → 8. Обучение

См. `/docs/SYSTEM.md` для полной спецификации.

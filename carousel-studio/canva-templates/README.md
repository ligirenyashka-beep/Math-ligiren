# Canva-шаблоны для сборки

Все карусели собираются как отдельные дизайны 1080×1350 px.

## Как дублировать шаблон
1. Открой в Canva: Создать дизайн → Пользовательский размер → 1080 × 1350 px.
2. Задай палитру (Brand Kit):
   - #FFFFFF белый
   - #F3E7D3 бежевый
   - #5A3A29 коричневый
   - #E8590C оранжевый
   - #6E1423 бордовый
   - #1A1411 почти чёрный
3. Загрузи шрифты: Unbounded (Bold 800), Manrope (600/700), Caveat (Medium). В Canva они есть в поиске.
4. Создай 10 страниц (копируй первую). Поля: включи Линейки → отступ 72px со всех сторон.
5. Загрузи иллюстрации из `carousel-studio/studio.html` → Экспорт PNG (или используй промпты для генерации).
6. На каждой странице:
   - Фон: из таблицы (бежевый/белый/бордовый/оранжевый)
   - Заголовок: Unbounded 72-84px, межстрочный 0.95, чёрный/белый
   - Тело: Manrope 36-42px
   - Реплика: Caveat 38px, поверни -6°, добавь стрелку
   - Формула: белая карточка 1080-144 width, 150 height, скругление 22, тень Y8 blur18
   - Номер: Manrope 12px внизу центр
7. Экспорт: Скачать → PNG → Все страницы (отдельные файлы) → загрузка в Instagram.

> Важно: Не проси генератор писать русский текст. Текст набирается в Canva как текстовый слой для чёткости на телефоне.

## Альтернатива без Canva
Используй встроенный движок `carousel-studio/studio.html` → Экспорт PNG — он уже рендерит типографику на Canvas и даёт готовые 1080×1350 без Canva. Canva нужен только для тонкой ручной правки.

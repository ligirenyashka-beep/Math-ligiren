# Math-ligiren — Пингли Академия

Полный курс математики 1–11 классов + платформа онлайн-обучения.

## Что внутри

### Документы курса (`docs/curriculum/`)
- `README.md` — карта курса и принципы
- `00-methodology.md` — методология: ФГОС/ФООП, ФИПИ, Сириус, МГУ, УМК, Корея/Китай/Сингапур, СССР, нейронауки, ТРИЗ/Монтессори/CPA
- `grade-01.md` … `grade-11.md` — отдельная программа каждого класса: цели, часы, темы по четвертям, коды ФИПИ, надстройка Сириуса/МГУ, нейроокно, контроль, медиа
- `assessment-bank.md` — система срезов: входная диагностика, тематические, четвертные, годовые, пробные ОГЭ/ЕГЭ
- `characters-video-intensives.md` — персонажи (Пинг, Ли, Навигатор, Профессор, Капитан Экзамен), план видеоуроков и мультфильмов, интенсивы, конспекты
- `platform-spec.md` — сайт, заявки, личные кабинеты (в рамках бюджета: статика + localStorage)
- `sources.md` — библиография

### Сайт (`site/`)
Next.js-платформа: курс 1–11, теория, практика, экзамены, интенсивы, персонажи, заявки, личный кабинет, дашборд родителя. Работает без сервера (прогресс в localStorage); при DATABASE_URL — PostgreSQL.

```bash
cd site
npm install
npm run dev   # http://localhost:3000
```

### Исходные материалы
- `Концепция Пингли Академии.pdf` — методологическая конституция (нейронауки + Монтессори + ТРИЗ)
- `developing-pingli-academy-platform (1).zip`, `developing-math-education-platform.zip` — прототипы платформы
- `visual_fractions_master.html`, `equations_immersion_master_v4.html`, `Qwen_html_20260814_qorq4dr6f.html` — тренажёры

## Принципы
Открытие (ТРИЗ) → Автоматизация (Монтессори); CPA: конкретное → наглядное → абстрактное; ошибка — данные; без таймеров давления; интервальные повторения 1–3–7–14–30 дней.
